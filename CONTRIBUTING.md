# Contributing

This is a public documentation showcase for a private project. Contributions here are limited to clearer explanations, corrections to the showcase, and improvements to fictional examples.

Before proposing a change, read [NOTICE.md](NOTICE.md) and the [roadmap](docs/ROADMAP.md). Keep capability status accurate and distinguish implemented foundations from future goals.

## Useful contributions

- Explain an architectural boundary more clearly without exposing private mechanisms.
- Correct a broken link, typo, or misleading capability description.
- Suggest a business workflow using fictional inputs.
- Improve the readability of an illustrative example without treating it as a production API.

## Keep public contributions safe

Do not include credentials, account identifiers, production configuration, logs, real messages, client data, private paths, private prompts, or security findings. Use invented entities and generic examples. Do not request access to the private source or publish material obtained from it.

Public bug reports should concern this repository's documentation or examples. Security concerns about the private system belong in an established private channel with the builder.

No open-source license is granted by this showcase. Contribution terms must be agreed with the builder before any contribution is accepted; opening an issue or submitting a proposal does not grant rights to the private implementation.
